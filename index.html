Doesn't match Instagram? 0

Your data export is a point-in-time file listing every handle in your graph when Instagram generated it. Instagram's own profile counter hides accounts it no longer serves — deactivated, deleted, and banned ones — so an export routinely lists more people than instagram.com admits to. Re-downloading the export never fixes that; finding those accounts and flagging them does.
